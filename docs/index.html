Security

Built to be trusted.

Your financial data goes from Plaid to your laptop and nowhere else.

Read-only by design

Balances, transactions and investments. fin never asks Plaid for account numbers or identity, and has no way to move money.

Nothing hosted

No server and no account with anyone but Plaid. fin talks to Plaid's API from your laptop and prints the answer.

Secrets in the Keychain

Your Plaid keys and access tokens live in the macOS Keychain. State is one file only you can read.

Made for agents

Tables for you, JSON for your agent, clear exit codes, and errors that say exactly what to run next.
